Jarvis ⚡

A private personal assistant.

Jarvis is a personal assistant that runs on its owner's own server and is used only by its owner. It is not a public service, and it does not offer sign-up to anyone else.

With the owner's permission, Jarvis reads the owner's own Google account data (for example email, calendar, files and Classroom) to help with organisation, reminders and summaries.
