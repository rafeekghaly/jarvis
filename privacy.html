Privacy policy

Last updated: 22 October 2026

Who uses Jarvis

Jarvis is a private assistant used only by its owner, on the owner's own Google accounts. No one else's data is collected through it.

What Google data it uses

When the owner connects a Google account, Jarvis can read and, where the owner allows, create or change: Gmail messages and drafts, Google Calendar events, Google Drive files, Google Docs and Sheets, Google Tasks, Google Contacts, and Google Classroom courses, coursework and announcements.

How it is used

  • Only to help the owner: summaries, reminders, deadlines, drafting documents and emails.
  • Sending an email, sharing a file or deleting anything needs the owner's explicit approval each time.
  • Data is stored on the owner's private server. To answer the owner, relevant content is processed by the AI model provider the owner has chosen.
  • Google user data is never sold, never used for advertising, and never shared with anyone else.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove Jarvis's access at any time at myaccount.google.com/permissions; its stored tokens are then deleted from the server.
